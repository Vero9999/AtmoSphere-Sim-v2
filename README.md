# AtmoSphere Sim v2

Environment Impact Prediction Tool for Batam, powered by **Gemma 4**.

Aplikasi web untuk memprediksi dampak lingkungan dari rencana pembangunan di Kota Batam.
(Work in progress — Hacktoberfest Hack Day Batam 2026.)

## Menjalankan

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
streamlit run app.py
```
